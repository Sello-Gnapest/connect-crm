# Connect CRM

Connect CRM is a modern sales CRM starter built with Next.js for a fast, scalable customer relationship management foundation.

## Features

- Dashboard overview for sales KPIs
- Lead pipeline and opportunity tracking
- Customer and account view structure
- Activity scheduling and follow-up flow
- Clean, responsive layout with Tailwind CSS

## Tech stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Getting started

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Project structure

- `app/` — app router pages and main layout
- `components/` — reusable dashboard UI sections
- `lib/` — mock CRM data
